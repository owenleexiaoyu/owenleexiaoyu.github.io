## 目标

本项目的目标在于开发 WanAndroid 应用的 3.0 大版本
该版本采用：
- KMP + CMP 作为主要技术栈
- 适配 Android、iOS、Desktop、Web 平台
- UI 重构，支持 Light Mode 和 Dark Mode
- AI Coding，我负责架构设计和少部分代码开发，大多数重复代码由 AI 实现
