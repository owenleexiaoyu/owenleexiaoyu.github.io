重新整一下 Obsidian Digital Garden 发布个人网站，这个网站现在的问题是插件和网站模板都在更新，同时我加入了个人主页和博客样式，自己改动了一些代码，和上游模板很容易发生冲突，需要找到一种方式能够持续同步上游的改动，同时保证自己的改动始终生效。

处理方式：
1. 从项目的 main 分支 checkout 一个用来备份的分支：`obsidian-digital-garden-backup-20260906`
2. 把项目 Clone 到本地，然后添加把 [DigitalGarden 模板项目](https://github.com/oleeskild/digitalgarden)  添加为远程仓库，名字设置为 upstream
3. 本地 main 分支 rebase upstream 的最新 main 分支，除了发布内容的改动，以及一个添加 Github Action 的改动，其他我之前做的改动（修改字体、修改 UI、增加个人主页、增加博客样式）都先不要（有冲突的直接 skip，没有冲突的，后面手动 Drap commit），这样就同步了上游模板的所有改动
4. 将 200 多个发布内容的 Commit 都合并成一个，这步本来自己手动操作，但操作出错了，还是靠 AI 抢救回来，找回之前的 Commit。最后还是直接让 AI 帮忙合并，又快又准确，再也不自己手动搞了。
5. 把本地 main 分支 force push 到远端，就完成了。

改完后，花园的主题又回到了默认样式，丑不拉几，我尝试修改了在线主题，但发现始终没有生效，让 AI 排查，发现竟然是我写的 Github Action 的脚本里有问题，设置了一个主题，会把在线主题覆盖掉，这个脚本应该也是 AI 生成的，我自己也不知道里面究竟有什么功能。让 AI 把脚本修复后，重新部署就看到线上新样式生效了。

期间 Obsidian Digital Garden 插件更新的功能：

- 可以配置 Backlinks 的标题和空文案，这个之前我也专门改了
- 大纲里如果不是从 H1 直接开始，之前会有缩进，并有一条竖线占着，现在修复了，即使最大的标题是 H2 或 H3，在大纲里也不会有奇怪的缩进了。
