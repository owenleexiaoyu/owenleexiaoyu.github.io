## 读后感

看这本书之前，看到评论区对他的评分不是很高，两个主要的点在于：

1. 文不对题：关键提问让人以为是介绍如何提好问题的方法论，但实际内容则是有些心灵鸡汤式的最重要的五个问题。
2. 内容水：明明五个简单的问题，还要凑成一本书。

看完全书，我不太认同这个说法。文不对题我感觉是译名的锅。这本书中译名为《关键提问：哈佛大学给毕业生的5 个人生思考题》，而人家原本的英文名为《Wait, What?: And Life's Other Essential Questions》，直译过来是《等等，你说什么？：和其他人生关键问题》，两者意思差得还是很大的。

关于内容水，我认为看这类鸡汤式文字，其实需要一些沉浸感或体验感，韩寒有句话说：「听过很多道理，却依然过不好这一生。」我想是这些道理只是干巴巴地听到了，却没有听进去，形成共鸣。如果只想知道这五个问题是啥，其实看简介就够了，但这样有用吗？是不是也只是知道了而己。作者通过他自身的一些经历，将这五个问题放到生活的场景中，尝试解释为什么它们如此关键。我们读者通过品读这些故事，对比自身，尝试在自己身上找出对应的反射，或许这样我们能有更多的感受和体会。综上所言，这本书确实给了我一些启发，我认为是本好书。

下面针对每个问题，来写下自己的一些感受。

==**第一个问题是「等等，你说什么？」**==

主要的目的在于缓一缓，先理解问题/事情，或者让对方再详细介绍下。避免对事情全景了解不清而妄下判断。我自己其实就挺需要提这个问题，工作中常有外部任务或需求，我的第一反应通常是先应承下来，再去自己仔细研究，但其实可以做的更好，比如多问一句：「你能再详细解释下吗？」获取更多的背景。和其他人交流时，也常常囫囵吞枣地被动接受他人的想法而没有缓一缓，确保自己真的理解这个观点，并做出回应（同意或反对)。

==第二个问题是「不知道为什么…」「不知道能不能...」==

告诉我们要多问为什么，因为这个问题是我们对这个世界的好奇心。我自己很少在公开场合发问为什么。自己可能有时会会想「...是为什么呢？」「…是怎么做到的」但这样的想法往往只是一闪而过，没有被抓住。这点正好在今天也有例证。中午吃饭的饮料是元气森林，一位同事最近得了糖尿病，没喝这个饮料，另一个同事说这个饮料零糖零卡路里应该没关系吧？这位同事就提了一个问题：「不知道这个饮料不加糖是怎么制作出这么多种口味的？」

同时这个问题也可以用来自问，也就是自我反省，比如「不知道我能不能做到...」，曾子说「吾日三省吾身」，说的也差不多是这意思。

==第三个问题是「我们能不能至少……?」==

这个问题主要适用于两个场景：

1. 出现分歧时，用这个问题来达成某些共识。

这是典型的退一步海阔天空的思路。也有一个善意假设的前提，以退为进。

先在某些点上寻找共识，再提出这个问题，「我们能不能至少在…上达成共识？」，再从共识出发，讨论对分歧的看法。

> 小萌补充了一个词「求同存异」，我觉得也很贴切。

我认为这个问题在生活中面对一些家人的争吵是很有用，比如两个大人对孩子的教育理念不同，可以提：「我们能不能至少在我们都希望孩子健康快乐地成长达成共识？」

2. 鼓励自己尝试新事物，走出第一步。这个确实挺有用，是一个心理的暗示。我们常常会担心某件事做不来，做得不完美，不知道从哪人事等原因而迟迟没有开始，而这个问题是一个走出第一步的机会。

比如，我想学英语，但是又怕坚持不下去，不如提问自己：「我能不能至少先读一段英语 / 读 5 分钟英语 / 背 5 个单词？」

这个问题的关键在于，这件事一定要是轻量级的，挺容易就能完成的，这样当它达到时，才能起到一些正反馈并产生「原来这也不难，我觉得我能做到」的心理感受。

万事开头难，这个问题就是为了降低开始尝试的门槛。

==第四个问题是「我能帮什么忙？」==

第 4 个问题主要讲帮助他人是很好的，但也要注意方法，不能有「救世主」的心态，摆出救世主的姿态，否则可能让事情变得更糟或好心办错事。

写着写着突然想起最近看的《狂飙》，高启强帮助刚出狱的老默，就很讲究方式方法，他并没有直接说我给你些钱做生意或者直接把鱼档送给他，而是说想让老默帮他个忙，替他照料一下现在没人看管的鱼档，这种反向帮助对于刚出狱很不受欢迎的老默来说非常感动，既顾及了他的面子也帮他解决了困难。所以后面老默才会对高启强那么死心塌地。高启强无疑是个很会问这个问题的人。

我们生活中常有打着为人好的口号帮忙，实际所做并不被领情的行为，特别出现在家人、父母与孩子，情侣之间这样的亲密关系中。

比如我的父母，面对我妹妹学习成绩不佳时，只是一味提醒，却不曾问一下「我能帮什么忙？」

这个问题也能表现出自己的同理心和同情心。

书中提到的表姐的例子让我想起我和小萌之间的一些故事。当时她找工作压力很大，也遭受了一些挫折，和我倾诉，我就从理性的解决问题的角度提了一堆建议，这并没有帮上忙，尽管那些建设可能是有用的，但她那时候需要的不是冰冷的建议，而是温暖的情绪支撑，或许我应该问「我能帮什么忙？」

==第五个问题是「真正重要的是什么？」==

这个问题主要是问自己，提醒我们要关注对自己真正重要的东西。比如，对于职业发展，最重要的是什么？对于家庭生活，真正重要的是什么？让我们把精力和注意力都放在这些重要的事情上。

我这阵子还挺勤奋，每天都花两到三个小时学习，但对我目前最重要的提升技术的事却还是没有什么进展，每次都把时间花在了其他可能比较好做的事上。我去年的一些学习，也是没有学最需要的知识。

这个时候就应该停下来问问自己，现在，真正重要的是什么。

想起之前看 [[NightWrite/191230 GTD 时间管理法则学习\|191230 GTD 时间管理法则学习]]，也提到面对那么多待办事项，应该优先做哪个呢？应该是做能让你离你目标更近的事。

OKR 的作用，也是可以让我们聚焦在真正有价值的任务上。

## 书摘
### 引言 问题不对，你永远不会成功

+ 我们不应把时间浪费在担惊受怕上——担忧过去、未来、不确定性、他人、新创意、新环境。
+ 通常我们心中最深的悔意源于不作为。
+ 第一个建议是，花更多的时间思考应该提出的问题。这并不是说答案是无关紧要、无足轻重的——问题与答案同样重要，甚至问题往往更为重要。道理很简单：答案的好坏是由问题来决定的。如果提出的问题是错误的，那么你得到的答案也将是错误的。
+ 人们所谓的‘发现的时刻’，其实就是发现问题的那一刻。
+ Siri、谷歌，以及沃森虽然在回答某些最基本的问题时做得很优秀，但并不是很擅长提出问题。
+ 要把带有贬义的问题与那些不得体但动机纯洁的问题区分开来。
    - 真正糟糕的问题，其实完全不能算是问题，只是伪装成问题的观点，意在提出苛刻的要求或是专门设置的陷阱。对于这些所谓的“问题”，保持警惕是有必要的。
    - 对于所有真诚的问题保持开放而接受的心态——包括不得体的问题在内——同样也有必要。
+ 问题就像钥匙。在合适的时间提出正确的问题，会打开通往你尚未知晓、尚未意识到，或是连想都没有想过的世界的大门，它或许是关于你自己的，或许涉及别人。

### 第一章 先理解，后下定论

+ 提问“等等，你说什么？”不仅能够帮助你厘清思路，也能够帮助他人梳理想法。在任何情况下，先让对方解释说明，再进行申辩。
+ 这个问题是一种寻求详细解析的有效方式，而详细的解析是真正了解某事的第一个步骤，无论是了解一个创意、一种观点、一种信念，还是一份商业提案。
+ “等等，你说什么？”也是一种避免妄下结论或草率判断的好方法。
    - 容易将错误的假设作为辩论和判断的依据。
    - 在家庭和工作中遇到困难的时候，这条经验尤为有效。在难以为继的谈话中，或是在感情冲动的情况下，暂停下来，询问你是否掌握了所有信息，得到了合理的结论，这一点总是很难做到的。
    - 不要在尚未解释清楚自己的思想之前，就让自己卷入不必要的争吵之中。

### 第二章 保持好奇心，建立新认知

+ “不知道为什么？”这个问题能够让你保持对世界的好奇心
+ “不知道能不能？”这个问题则能让你加强与这个世界的沟通，也是一种鼓励你尝试新事物的方法。这种方法还能让你迈出第一步，思考如何让世界变得更加美好，或至少在你所在的小领域做出改善。
+ 阿尔伯特·爱因斯坦在一次很经典的“低调自夸”中说道：“我没有什么特殊的才能，只是好奇心极强而已。”
+ 绝大多数人对于这个世界的好奇心都会随着年龄的增长而递减。
+ 对当下提问“不知道为什么？”会自然而然地让你对未来提出“不知道能不能？”这个问题。
+ 如果没有人提问“不知道为什么？”以及“不知道能不能？”，如果人们没有拒绝接受不可避免的现状
+ 想要改变现状，第一步就是提出“不知道为什么？”，然后在这个问题后面再附加“不知道能不能？”这个问题。
+ 这两个问题不仅适用于针对周围的环境提问，还可以拿来扪心自问。我并不是在宣传自我提升的课程，也没有鼓励大家反躬自省，我只是觉得，对自己保持好奇心的做法既有助于健康，又有助于成长。

### 第三章 后退一步，前进两步

+ 提问“我们能不能至少……”是一种破解僵局的好方法。这是一种超越分歧、达成某种共识的好方法。
+ 是一种寻找共同立场的方式。
+ 在后退一步、找到了一些共识之后，你或许就具备了前进两步所需的条件，而这往往也是人们达成进步的方式：后退一步，前进两步。
+ 无论是在线上还是在线下，当想法相近的人们聚集在一起的时候，往往会巩固彼此的看法。他们不仅加强了彼此的信念，还往往会在有意无意间将彼此引向更为极端的立场。
+ 提问“我们能不能至少在这一点上达成共识？”是一种对抗两极分化和极端化的方式，因为这无异于一种寻求在某些领域达成共识的邀请
+ 想要规劝别人接受自己的观点，第一步就是找到一些共同立场。
+ 这个问题无法解决所有的意见不合，但这至少可以化解一部分的分歧。
+ 提问“我们能不能至少……”也是一种促进行动的好方法，即便是在尚未做好完整规划时也可以用。
+ 每次尝试着伸出一只援手、纠正一个错误，或是勇敢表达内心真实想法的时候，你对这个世界以及对你自己的看法也会有所改观
+ 大胆尝试后遭遇失败要好过在旁观望。
+ 如果你在尝试的过程中失败了，你所遇到的最坏的情况，往往不过是给你的生活增加了一个有趣的谈资——我还从来没有听过任何因为没有去尝试而产生的趣闻呢

### 第四章 不要表现出“救世主”姿态

+ 我们还是不应该让“救世主情结”中这个实际存在的缺憾掩盖我们最富有人性的本能之一，也就是助人一臂之力的本能。
+ 关键在于，在帮助他人的同时，不要认为自己是“救世主”，也不要表现出“救世主”的姿态来。
+ 提供帮助的方式与提供帮助本身同等重要。
+ 用“我能帮什么忙？”这个问题引出对话才如此关键。用这个问题来开头，表明你在抱着谦虚的心态寻求指点。
+ 提问该如何帮忙这个问题不仅向对方表达了尊重，还很可能让你的协助更有的放矢
+ 询问该怎么帮助对方，也是一种鼓励他人认识、表述，以及面对问题的有效方法。
+ 癌症病人和他们的家人所需要的，就是有人能够以坦诚和怜悯之心帮助他们指点方向。
+ 我发现，这个问题对于做父母的人来说非常管用，用在成绩不好或情绪不佳的学生身上也很有效。父母们（以及老师们）会尽力处理各种问题，他们往往认为自己知道解决方法，因此会提供自己的一些见解——或是一大堆的见解。
+ 提供解决方案只会让孩子或学生的焦虑感加剧。反之，如果你能耐心而安静地聆听他们的顾虑和怨言，然后再询问该怎么帮忙，那么对话也会有所改变。
+ 发牢骚的需求不仅限于孩子。我那风趣聪慧的表姐特蕾西给我讲过一个故事，说她在经历了令人沮丧的一天之后，下班回到家，向男友诉说一天的经历。她的男友并没有听完整个故事，而是立刻提议她在当下该采取什么行动以解决问题。男友的回应让她大为恼怒。她告诉我：“我并不想让他来解决我的问题，只是想让他做我的听众，知道我那天在工作上不顺心而已。”
+ 询问朋友、家人或是同事该如何帮忙，并不意味着你是在提供具体的方案，为他们解决问题。这样做其实是在证实他们确实有问题，并且向他们表示，如果有需要，你便能够提供帮助。你既表达了同情心，又表达了同理心，而这也是每个人偶尔都会有的需求。换句话说，通过提问该如何才能帮忙，有的时候，你其实已经帮了大忙。
+ 通过提问该怎么帮忙，你与对方的对话以及关系就能建立在更加平等的基础上。
+ 提问该如何才能帮忙就像是一封邀请函，能开启一段以互利互惠为基础的真挚感情
+ 没有人能够明了这一生的终极意义，即便如此，我们现在最重要的任务还是去观察和品味身边稍纵即逝的美好。
+ 如果你能主动提出帮助某人，并且敞开心扉地接受他人的帮助，你就能逐渐理解弗罗斯特在诗歌中所说的“这就是爱，除此之外，别无他物”。

### 第五章 谨慎分辨重点和无关信息

+ 这个问题会驱使你在工作和学习中遇到困难时深入关键点，也会逼你直击生活中的观点、信仰，以及目标的核心。这个问题能够帮助你区分真正重要的问题和微不足道的问题，并能帮你在追求重大目标的过程中撇开细枝末节。
+ 这个问题让你得以摒除那些分散注意力和偏离主题的因素，以及无关紧要的细节，让你将注意力专注在必须要完成的、既实际又重要的任务上。
+ 我们只要小麦，不要谷壳；只管事实，不顾虚像
+ 我们应该尽可能地提高工作效率，以便能完成工作之外具有同样重要意义的事情，比如与家人和朋友共度时光，或是追求其他的兴趣和爱好。
+ 提问真正重要的是什么，并从问题的答案中获益。
+ 这是一个很好的总结人生的方法。这个问题也适合在每次跨年的时候提出。
+ 关键在于，你不仅要找出那些对你重要的领域或主题，还要深入考虑你在哪些方面进展不错，在哪些方面可以再接再厉，以及其背后的原因。

### 结语 人生如是，你是否获得了你想要的东西？

+ 当你的人生走到尽头，你所看重的东西会是什么。据我估计，到了那时，在你所给出的答案中，物质利益只会占很小的比重，而你与他人之间的情谊才会是你人生的关键。
+ 人生如是，你有没有从中得到你想要的东西？
+ 想要拥有受人爱戴的感觉，那就帮助他人获得同样的感觉。
