《谁动了我的奶酪？》是美国作家斯宾塞·约翰逊创作的一个非常简短而富有哲理的小故事，于 1998 年首次出版。

故事中有四个小家伙，两只小老鼠「嗅嗅」「匆匆」，他们大脑简单，但直觉敏锐；两个小矮人「哼哼」「唧唧」，拥有复杂的大脑，里面充满了信念和情感。他们生活在一个巨大的迷宫中，每天都在其中跑来跑去寻找奶酪。小老鼠嗅嗅和匆匆寻找奶酪的方法很简单，就是反复尝试，嗅嗅嗅觉敏锐，可以嗅出奶酪的大致方向，匆匆就会立即出发，他们会经常迷路、撞墙，但他们一直在尝试。小矮人哼哼和唧唧会运用自己的思维能力，在实践中不断总结教训，摸索出一套自己的方式来寻找奶酪。

有一天，他们在奶酪 C 站里发现了无数各式各样的奶酪。之后的每一天，他们都会跑到 C 站来享用奶酪，不久，他们都形成了固定的习惯。嗅嗅和匆匆每天早晨仍然很早起来，到达 C 站，将跑鞋挂在脖子上，以便可以迅速穿上；哼哼和唧唧则一天起的比一天晚，慢悠悠地走到 C 站，因为他们已经知道奶酪在哪，如何找到奶酪了，不需要那么辛苦了。到了 C 站后，他们会脱下运动服，收起跑鞋，换上拖鞋，把 C 站当成了自己的家。

这样美好的日子持续了很长一段时间，直到某一天早晨，嗅嗅和匆匆来到 C 站后，发现奶酪已经没了，他们并没有感到很惊讶，因为他们每天都会在奶酪 C 站附近跑跑探探，也会检查奶酪的情况，他们已经注意到奶酪在一天天减少了，知道这一天迟早会到来，所以做好了准备。他们取下脖子上挂着的跑鞋，穿好后开始按照以前的方式在迷宫中奔跑，寻找新的奶酪。

> 小老鼠是从来不会进行过多分析的。对他们来说，问题和答案都同样简单，奶酪 C 站的情况已经发生了变化，因此嗅嗅和匆匆也决定改变。

那天晚些时候，哼哼和唧唧如往常一样，悠闲地来到 C 站，他们一直没有注意到奶酪站里每天发生的细微变化，而是想当然地以为他们的奶酪肯定还在那里，所以当他们发现 C 站里没有奶酪后，他们大吃一惊。哼哼咆哮道：“谁动了我的奶酪？”，这就是书名的由来。奶酪对他们来说，不仅仅是填饱肚子，还意味着悠闲的生活和安全感、权利等精神上的满足。他们无法相信眼前的事实，大声控诉这一切是多么不公平。晚上，他们饿着肚子垂头丧气地回家了，第二天，他们又来到 C 站，祈祷奇迹发生，然而并没有，奶酪站里还是空空如也，他们再次感到巨大的失落与愤怒。唧唧提议他们应该出发去迷宫里寻找新的奶酪，但哼哼却不同意，他认为奶酪是自己应得的，别人拿走了他的奶酪，应该给他补偿。

当哼哼和唧唧在商量怎么办时，嗅嗅和匆匆已经在迷宫中奔跑很久了，他们进入了迷宫深处，尝试了一条又一条路，花了很长一段时间，终于有一天，他们发现了一个新的奶酪站——N 站。他们为找到梦寐以求的新鲜奶酪而高兴地欢呼。

哼哼和唧唧每天都会去 C 站，看看奶酪会不会回来，他们变得越来越虚弱，越来越暴躁。唧唧厌烦了无休无止的等待，他逐渐明白，拖得越久，自己的情况就越糟糕。他并不喜欢重新在迷宫中奔跑、寻找，因为他知道自己会迷路，也不确定出去该到哪找新的奶酪。但是想想恐惧对自己的影响，他忍不住嘲笑自己的愚蠢。

唧唧重新穿上运动鞋，准备重新到迷宫中寻找奶酪，哼哼试图说服他不要去，但唧唧最终还是下定决心。为了克服恐惧，唧唧为自己构建了一个非常美好的想象画面，画面中他最终找到了新的奶酪，并且正在享用各种美味的奶酪。唧唧捡起一块石头在墙上写下一句话，希望能鼓励到哼哼，让他开心并且重新振作起来。

> 如果不改变，你就会被淘汰。

唧唧终于走出奶酪 C 站，踏入黑暗的迷宫，慢慢跑向未知的领域。他很久没有吃到奶酪了，身体变得很虚弱，跑得比以前慢，而且更加吃力，他反思自己应该早点适应变化，离开安乐窝。接下来的几天里，唧唧只找到了零星的一点点奶酪，他对未来仍然感到很迷茫，更糟糕的是他在迷宫里迷路了，他开始怀疑自己是否还能找到新的奶酪。每当他感到丧气时，唧唧都会鼓励自己，现在虽然辛苦，但是总比呆在 C 站好的多，自己现在掌握了主动权，而不是消极地等待。他同时也回想起来，C 站里的奶酪自己之前以为的一夜之间突然消失的，而是逐渐消失的。事实上最后奶酪不仅数量少了很多，也没有那么新鲜了。他意识到，如果自己密切观察并且预测到变化的话，当 C 站空了，他不会手足无措。他在墙上写下：

> 经常嗅一嗅奶酪，这样你才知道它是否依旧新鲜。

有一天，唧唧终于找到一个很大的奶酪站，但里面是空的，这样的失落他已经体验过很多次了，他简直想放弃了。唧唧的体力越来越差，他知道自己迷路了，很担心自己能否活下去，他想过回到 C 站，至少不会孤独了。他以为自己已经克服了恐惧，但事实上他恐惧的次数越来越多。他有时也会想哼哼有没有走出 C 站，为了提醒自己，也为了给哼哼留下路标，他在墙上写下：

> 朝着新的方向前进，你就会发现新的奶酪。

唧唧看着黑暗幽深的走廊，清楚地感觉到自己内心的恐惧，随后他摇摇头，意识到恐惧只会让事情变得更糟，因此他决定不再胡思乱想，向着新的方向进发。唧唧已经放下了思想包袱，找到了奋进的动力，这次，他的感觉越来越好，他也很疑惑：“为什么会这样呢？明明我一块奶酪都没找到”，不久后他明白了，在墙上写到：

> 当你克服了恐惧，就会感到轻松和自在。

唧唧意识到，自己一直被恐惧所俘虏，向着新方向出发释放了内心的恐惧，他感到浑身充满了活力。为了鼓励自己，唧唧又在脑海里想象自己坐在一堆奶酪中间品尝各种美味的奶酪的画面。脑海中的画面越清晰，感觉也越真实，他预感自己很快就可以找到奶酪了。他停下来在墙上写下：

> 想象自己正在享受奶酪，这样可以帮助你找到新的奶酪。

不久后，唧唧发现了一个奶酪站，并在门口找到了一小块新奶酪，他兴奋极了。但走进奶酪站，里面确是空的，已经有人捷足先登了。唧唧想，如果自己早点离开 C 站，就可能在别人之前找到这里。他决定回 C 站叫哼哼和自己一块出来寻找新的奶酪。回去之前，他又写下新的感触：

> 越快放弃旧的奶酪，你就可以越早享受新的奶酪。

很快唧唧回到了 C 站，它把新奶酪拿给哼哼，但被拒绝了，哼哼说：「我不喜欢新奶酪，我只想要把自己的奶酪要回来」。唧唧失望地离开了，虽然心里十分怀念自己的朋友，但他明白，继续探索和寻找才是自己想要的生活，新奶酪并不是让自己开心的唯一原因，他为自己能够摆脱恐惧而感到开心，他喜欢现在的生活。意识到这些，他感觉自己浑身都充满了力量。

> 在迷宫中搜寻，总比停留在没有奶酪的地方更有保障。

唧唧再次想到，自己一直担心的事情没有想象中那么糟糕，心里滋生的恐惧比现实更麻烦，担心和恐惧禁锢了他的思维，让他总是患得患失，不思进取。他过去总是以为奶酪一直都会留在那里，变化都是不公平的。现在，他意识到，不管你是否希望，变化总是会不断出现的。但是，只要你做好准备，变化就不会让你惊慌失措。

> 抛弃旧的观念，才能找到新的奶酪。

唧唧明白，**观念变了，行为就会跟着变化**。你如何看待变化，抵制它或者拥抱它，会决定你的行为。

> 只要相信自己能够找到并且享用新的奶酪，你就会改变自己的行为。

唧唧在想，如果自己早点应对变化，离开 C 站，自己的身体和精神状态会比现在好很多，能够更好地应对寻找新奶酪的挑战。在迷宫深处的寻找中，唧唧偶尔会找到一些零碎的奶酪，他也逐渐恢复了体力和信心。回顾走过的历程，他很高兴自己在那么多地方留下了感言，如果哼哼有一天离开 C 站，这些感言将会指引他游走与迷宫之中。唧唧又写下自己最新的思索：

> 及早注意细微的变化，这会有助于你适应即将到来的大变化。

唧唧在沿着一条从未走过的走廊向前奔跑时，在拐角处的奶酪 N 站发现了新的奶酪。一进去，他就被眼前的情景惊呆了，房间里堆满了各式各样的奶酪，有些品种他以前从来都没见过。唧唧站在那里愣了一会，他不确定这是不是他的幻觉，这时他看到了自己的老朋友嗅嗅和匆匆，他们对他点点头、挥挥手，以示欢迎。圆圆的肚子表明他们已经在这里待了一段时间了。唧唧飞快地跟他们打了个招呼，接着就开始品尝起美味的奶酪。然后他脱下鞋子，把鞋带系在一起，挂在脖子上，以防以后要用到。「耶，变化万岁」，唧唧拿起奶酪大声喊道。

在享受新奶酪的同时，唧唧也在反思最近学到的东西。他意识到自己的改变主要是在学会嘲笑自己和自己所做的傻事之后。**改变自己最快捷的方式就是嘲笑自己的愚蠢，这样才能对自己的过去释然，从而迅速朝着新方向前进。** 同时他也从老鼠朋友嗅嗅和匆匆那里学到了一些有用的东西，他们把生活看的很简单，从来不会像自己和哼哼那样没完没了地分析。在形势变化之后，奶酪不见了之后，他们也跟着奶酪一起变化。

他得到以下这些经验：

+ 有时需要简单地看待问题，灵活、迅速地行动，不要用可怕的固有观念把事情变复杂，让恐惧的念头把自己搞得心烦意乱。
+ 要密切关注微小的变化，这样就会为可能来临的大变化做好准备。
+ 要想作出改变，最大的障碍来自自身，除非自己想改变自己，否则一切都是枉然。
+ 新的奶酪总是存在的，如果你克服恐惧、乐于探险，就一定会得到回报，你将在探索中找到新的奶酪。
+ 某些恐惧是有益的，它们可以帮助人们避开真正的危险，但自己大多数恐惧都是不理性的，会妨碍自己在必要的时候做出改变。

唧唧本来想回到 C 站，找到哼哼，告诉他如何走出困境，但他仔细想了下，自己已经努力帮助哼哼了，但是没有效果。哼哼必须肚子克服贪图安逸和恐惧的心理，自己去寻找前进的道路，这个过程没有人能够代替他，或者说服他。自己在迷宫中给哼哼留下了标识，如果哼哼愿意读一读墙上的留言，是能够找到出路的。

于是唧唧打消了回去找哼哼的念头，他把自己学到的教训总结起来，写在 N 站最大一面墙上，还在这些感言的旁边画了个大大的奶酪。

![](https://s2.loli.net/2022/09/08/3LiYwUzcfx6MXQF.jpg)



> **变化总是发生**：他们总会不断拿走奶酪。
>
> **预测变化**：时刻做好失去奶酪的准备。
>
> **密切关注变化**：经常嗅一嗅奶酪，这样你才知道它是否依然新鲜。
>
> **迅速适应变化**：越快放弃旧的奶酪，你就可以越早享受新的奶酪。
>
> **变化**：随着奶酪的变化而变化。
>
> **享受变化**：尽情享受探险的过程和新奶酪的美味。
>
> **做好迅速改变的准备，享受其中的乐趣**：记住，他们总会不断地拿走你的奶酪。

唧唧现在和在 C 站时已经有了很大的不同，他每天都会检查 N 站里奶酪的情况，他还会尽力做好准备，以免新的变化到来时不知所措，他会经常跑到迷宫里探索新的区域，了解周围的情况。

突然，唧唧听到了迷宫里传来一阵响声，并且越来越大，是有人来了，来的会是哼哼吗？

==随着奶酪的变化而变化，并且享受变化。==
