记账和投资实证记录，已经坚持了很多年，每个月记录一次，使用「钱迹」「有知有行」等应用来记录，再整理到语雀的文章里。今年开始，这个工作有了新的变化，我和小萌开始作为一个家庭来记账，在记录我个人资产的同时，还增加了记录家庭资产的环节。
# 家庭记账

在进行一月份支出记账的过程中，想清楚了如何进行家庭记账：
- 设置一些重要项目的分类，比如婚礼、旅行等。不管是吃、住、交通、购物等，只要是该项目有关的支出都记在这个分类下。
	- 增加一个婚礼标签，把 2025 年产生的和婚礼有关但不在这个分类下的支出一起按标签来统计总数
	- 不同的旅行项目，用标签进行区分，如「重庆旅行」、「苏州旅行」等
- 除了重要项目，剩下的就是日常的支出，日常支出包含以下分类：
	- 用餐
	- 交通
	- 学习
	- 住房（目前租房阶段特指房租）
	- 医疗
	- 人情捐赠
	- 家人（为双方直系亲属：爸妈、奶奶、外婆，和亲兄妹的支出，其他算在人情中）
	- 恋爱（为对方买的一些礼物的支出，小萌和啸宇两人的转账不计入开支）
	- 日常（除了以上这些分类，像日用品、看电影、打球等运动都算在这个分类中）
- 对于日常支出，设置两个个人标签：啸宇，小萌，从啸宇这边产生支出和收入打上「啸宇」标签，从小萌这边产生的支出和收入打上「小萌」标签
- 保证每笔支出和收入都有一个标签（要么是项目标签，要么是个人标签）。

记了两个月的账，发现目前记账的最大问题是，日常每一笔消费（尤其是小萌每天吃饭的账单很多）都记的话，条目太多，记录费时费力，怀念之前往小荷包充值 1000，不管明细如何，只记一个总额。

# 投资记账

除了支出记账，我还要记录我的投资记账，并更新我的个人资产。我的账户参考「四笔钱」的概念，分为「活钱零钱」（微信支付宝、银行活期、货币基金等）、「长期进取」（有知有行黑板报、有知有行定投温度计、长赢 S 定投、长赢 150 份、云长进取、螺丝钉组合等）、「稳健增值」（春华秋实、诸葛稳健等）。每个月进行投资记账时，会在有知有行 App 中记录各个账户间的金钱转移（买入、卖出等）、以及当前各个账户的资产总额，就能自动统计出每个账户的投资收益率。

以往的操作方式是，对于从「活钱零钱」转到「长期进取」「稳健增值」等账户的投资，不算日常支出，从对应账户卖出基金获得的钱转回「活钱零钱」，也不算收入（是投资的收益）。买入和卖出的操作，我会在有知有行上用转移到其他账户方式进行。再加上我一个月的日常支出收入之差，就是我活钱账户的资金进出了。再更新当前的数额，就能够知道所有的收益。这个方法之前运行良好，现在有了新的变化：第一是我们现在开始大规模使用信用卡了，信用卡的消费，日常记账时会算，但因为他没引起账户数额的变动，在投资记账里不算支出，要把这部分账单剔除。第二是我和小萌之间的转账，对于日常开支，它其实没有花出去，只是在我们的账户里转移，所以在消费记账里不算支出，但是因为引起了我们账户数额的变动，在投资记账里算支出和收入，所以这些钱要加上。

我在二月底进行了第一次投资记账，操作方式如下：买入卖出的金钱转移部分还是和以前一样，没有变化。对于「活钱零钱」账户的支出收入部分我目前是这么做的：微信，支付宝，招商银行三个支付渠道，筛选出要记录到投资账中的收入和支出。
- 微信有个小账本，会自动同步账单，把用信用卡的账单都删掉（每月末记账时操作一遍即可），剩下的就是需要的。
- 支付宝本来就是在账本里了，可以增加标签，按标签统计收支，我把非信用卡的支出和收入打上一个“记入投资账”的标签，就可以按月统计出要的数额。
- 招商银行就麻烦点，要识别出那些是微信支付宝重复的支出，找到直接在招商银行转入和转出的账单 包括我的工资，和小萌之间的转账，这里没有什么方便用的工具，只能手动筛选手动计算，不过应该条目比较少，在可操作范围内。

想到两个方式让记投资账更简单点：尽量所有开支收敛到信用卡，然后在微信支付宝放一些钱，保证在不能用信用卡的时候，转入转出只发生在各自渠道，不到招商银行里，不产生重复账单。

# 家庭资产

通过有知有行 App，记录家庭资产非常简单，首先在家庭资产板块中已经有了我这个角色，把我的个人投资账户映射到家庭记账的几个账户：流动资金、固定资产、投资理财、应收款、负债。映射关系如下：
- 「活钱零钱」 -> 流动资金
- 「其他资产」（公积金、公司期权） -> 固定资产
- 「长期进取」「稳健增值」 -> 投资理财
- 「负债」（花呗） -> 负债
- 暂无应收款
每次更新了投资记账后，数据就会自动同步到家庭记账里，不需要我去额外记录。然后是小萌的部分，在家庭记账中增加一个小萌的角色，然后每个月底将她各个渠道的钱记录到对应账户里即可（小萌没有投资记账，简单很多）。
- 银行卡、微信支付宝 -> 流动资金
- 公积金 -> 固定资产
- 信用卡 -> 负债
