通常的招聘流程分为以下几步：
简历筛选   ——   笔试  ——  面试。

## 如何准备

计算机类校招需要如何做准备，以及该准备哪些方面的内容，按照我之前的经验，，大致可以分为 3 部分：

1. 准备简历
2. 收集招聘信息
3. 复习知识技能

一个个来介绍下。

### 简历

简历是找工作的敲门砖，一份格式混乱、内容普通的简历可能在简历筛选时就被淘汰，而一份好的简历能够收获更多的笔试、面试机会。

怎样才算是好的简历？

我认为至少要满足以下几点：

+ 简历要好看点：这里的好看是指视觉上的。比如排列需要整齐，文字的字体字号需要有一定规范并且全篇保持一致，有相对简洁好看的模板，不用特别花哨但也不能只是堆一堆文字。
+ 简历的篇幅要适中：一般校招简历写一页即可，多了内容注水严重，少了显得没有内容，尽量是把一页填满就好。
+ 简历的内容要有选择：简历一般需要以下组成元素：
    - 个人信息：名字、联系方式、邮箱、证件照等等
    - 学历信息：本科及硕士的学校（包含时间）、专业、主修的课程等，如果绩点比较好还可以把绩点加上
    - 项目信息：在学校里或者实习阶段参与过的项目，项目简介（包含时间）、自己在项目中承担的角色和所做的工作，重点在于突出自己在项目中贡献。
    - 技能信息：所掌握的计算机相关的知识和技能，比如写「熟悉数据结构与算法」「熟悉 Java 编程语言」「熟悉前端开发，掌握 HTML、CSS、JS、Vue 等开发技能」等等，比如一些加成的技能，主要是英语水平，英语四级或六级。其他像 Office 软件使用之类的就不用写了，写了反而拉低水平。如果第一版简历这里的内容不够丰富，就说明准备的还不太充足，需要有针对性地学习和复习。
    - 自我评价：对自己的评价，一般写自己热爱编程，勤学好问，态度端正，有良好的沟通协作能力之类的，重点在于展示自己的**软素质**。
    - 其他的内容可以视情况补充......

> PS：投递简历一定要用 PDF 格式，不能使用 Word 格式。Word 在不同电脑上可能会排版错乱，非常不专业。

### 招聘信息

在找工作时，广泛地搜集和目标岗位有关的招聘信息很重要。如果其他东西都准备的很好但因为没有关注招聘信息而错过简历投递那是非常可惜的。

收集招聘信息主要包含两个方面，一个是找公司，一个是找岗位。

首先是需要确定想要找什么方向的工作，比如前端开发、客户端开发、后端开发等。

第二步是去招聘平台上去搜寻合适的岗位和公司，寻找自己希望加入的公司，一般大公司比较耳熟能详，小公司则需要再进一步找找相关材料，主要做什么，有没有什么负面消息，比如欠薪等等。

常见的互联网招聘的平台：

+ 拉勾网
+ Boss 直聘
+ 猎聘

对于大公司，如阿里、腾讯、百度、字节、美团等，还需要关注它们的招聘官网、公众号。

其次还应该关注一些校招咨询平台，最典型的就是「[牛客网](https://www.nowcoder.com/)」，这里可以刷编程题，也可以找岗位，还可以加入一些圈子，和其他正在找工作的人一块交流，了解更多资讯，比如面试经验等。

### 知识技能

俗话说，打铁还需自身硬，如果没有好好准备笔试面试所需的知识和技能，那么即使简历包装得再好看，再牛逼，收获了无数的笔试和面试，到了最后也还是会被无情淘汰下来。

计算机方向的知识技能我大概分为 4 点：

+ 通用型（基础型）知识：包括操作系统、计算机网络、算法与数据结构、计算机组成原理、编译原理等等，这些是八股文重灾区
+ 算法能力：主要是笔试或者面试中会有算法题，就需要在准备阶段多刷题，比如剑指 Offer、LeetCode 等
+ 领域知识：特定方向的技术栈知识，比如前端开发需要熟悉 HTML、CSS、JS 等知识；比如后端开发需要熟悉 SpringBoot、MySQL 等知识
+ 项目：需要有一两个确实真实参与的项目，以前端开发为例，需要有一两个比如用上了 Vue 或 React 目前比较主流的框架的项目，不用特别大，但需要是自己写的，有自己的理解。比如用 Vue 仿写一个豆瓣，或者做一个音乐播放器之类。

## 求职策略

+ 找工作没有什么捷径，就是海投，海面。
+ 注意好投递简历的时机，一般来说，可以先投一些并不打算去的公司，比如一些小公司，获得面试机会，提前锻炼面试表现。把想去的公司稍微往后放一点，不过也要注意不要超过投递简历的截止时间。在适中的时间投递简历，太早没有准备好，成了炮灰，太晚招满了，简历过不了。所以这个要灵活处理。
+ 安排好复习和面试的节奏，建议是以 3、4 这两个月为目标，安排整体的计划，比如前一两个星期，先不投简历，专心复习一阵子，把各种需要准备的知识看个大概，两个星期后，开始边投简历面试边复习，查漏补缺。
+ 笔试、面试之后的复盘很重要，将笔试题面试题记录下来，形成自己的面经，同时去网上搜索，看看自己的回答是不是准确，有没有遗漏，把一些标准答案记录下来。面试时，可以开个录音，结束后，自己再听一听，一方面方便整理面试题，另一方面站在别人的视角下回顾自己的面试表现，对语言表达之类的细节进行总结，下次面试时加以改进。
+ 面试时，即使遇到一些不会的问题，也要尽力去思考，尝试从自己已知的知识中获得一些可能的想法，并说出来，这样可以表现自己肯动脑筋等方面的软素质。

## 预期管理与心理建设

现在互联网也没有之前那么火热，甚至是被称为互联网寒冬，所以今年的求职是会比较难的，这个要做好心理预期，可能会碰很多壁，比如简历被拒、面试被拒等等。遭遇失败必然会产生受挫心理，压力也会比较大，但这个过程中，最重要的是要及时调整自己的心态，如果烦了、沮丧了，可以去跑跑步、出去看看电影、听听歌、吃吃东西、和朋友聊聊天，总之是换换心情，及时排解心里的负面情绪，不使其堆积。并且需要直面这些情绪和失败，不让负面情绪操控自己，只有从失败中汲取经验、更加努力复习，才能从正面战胜挫折，取得成功。
