小萌被蔚来的销售推销试驾有抽奖，预约了今天下午去试驾蔚来的 ET5T，门店是在五角场的合生汇。其实我一直非常喜欢 ET5T 这台车的旅行车造型，车身线条和比例都恰到好处（外观可吐槽的点是眯眯眼大灯太小气，车顶除了中间一个激光雷达，两侧还有凸起的摄像头，像两个牛角）。这次去到店里，看到蔚来的内饰设计也是非常出色的，尤其车机那个圆角，非常圆润，让人看着很舒服。

试驾还是在新江湾城附近，工作人员先把车从合生汇开出来，前往新江湾城。期间给我们介绍这台车的基本情况以及试用智驾，到了新江湾城后再交给我开。作为汽车小白，我实在难以区分不同车驾驶感受的区别，我开起来感觉挺好的，跟上次试驾的极氪 007GT 挺像的。是比较舒服的，不会很颠。小萌说坐在后排也是挺舒服的。蔚来的智驾开的比人还激进，几乎没有提醒手握在方向盘上，长距离的待行区识别不了。我觉得它的智驾的逻辑有点奇怪，有时明明可以不变道的会变道，有一次前面拥堵时，甚至停在两条车道中间了，这不会扣分吗？

这个车 29.8 万，租电模式 19 万，现车优惠 6000，嘉定区补 4000，部分选装半价，情绪价值给足的 Nomi 原价选装 4900，现在 2450。100 度电池每月租赁费用 1128，75 度电池每月是 700 多（具体多少忘了）。可以 0 首付 0 利息，贷 5 年，前 3 年免息，后面两年年化 3%。购置税大概8000 多，保险 8000 多。100 度电池续航 710 公里，这个续航好像有点一般。看网上说这车是 NT2.5 的平台架构，太老了，还是 400 伏电压，这在现在不太够看。

我发现这些销售的话术就是只讲好的，不讲坏的，不实在。比如我问这车是 400 伏，销售说高压没有意义，换电三分钟，等效 2000 伏，这还能这么说么？我和小萌说坐在后排，腿伸不到前排座位底下，销售说你后排会坐人吗，他的车后排从来没有坐过人。然后智驾永远自己是第一梯队，说小米、极氪的智驾不如蔚来的，但好像蔚来的智驾印象中并不是很突出哇。

销售跟我们聊完报价，我们表示再对比考虑下，其实就是婉拒。结束后小萌的抽奖抽中两张饮品兑换券，在牛屋兑换了一杯橙汁和一杯冰美式。牛屋里有很多车主在这里坐着，还有小孩在一个小房间玩耍。我还保持着清醒，倒是小萌在听到他这 0 首付 0 利息的金融政策有点上头。
