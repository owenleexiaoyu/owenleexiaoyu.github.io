今天作为影子面试官参与了一场面试，看候选人的简历上的经历和我很像，结合我参与的这场面试他的表现，以及整个面试环节其他面试官对他的评价，感觉很有感触，记录一下。

候选人 19 年参加工作，大概 4 年半的工作经验，和我一模一样；主要做业务开发，我也一样；做过代码分仓，我搞过组件化，也有代码分仓；接过安全 SDK，我也接过，负责 SDK 在 App 中的升级；做过一些合规需求，我主要做的就是合规需求；做过代码从 Java 转 Kotlin，MVP 转 MVVM，我在工作中也常用 Kotlin、MVVM。不夸张滴说，这个候选人简直是「世界上的另一个我」，这也是我感慨的起源。

但他面试基本上是一面就挂了（后面捞了一次，由面了两次，我和另一个同学参与了二面，给了通过，后面 Leader 3 面又给他挂了），总结来说原因主要是技术不扎实，没有深入理解一些底层原理，很多东西只是停留在知道或听过的阶段，没有深究。也没有对自己的经验、业务领域知识做总结，业务理解能力弱。

我仿佛从他身上看到了我的影子，并且因为是作为面试官的身份，相当于站在另一边审视自己，这个过程中能看到他的很多问题，也能映射到我自己身上，并且更加深刻。

最明确的一点是：停留在表层，不深入。对很多知识只是知道，了解，会用，但不是完全掌握了，理解了，一问原理就懵逼了。

明年我最大的挑战或目标就是深入探索，增加自己知识的深度。
