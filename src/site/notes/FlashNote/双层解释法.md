这个 Prompt 适用于「这个概念我完全不懂」的场景。

相关 Skill：[[FlashNote/ELI5\|ELI5]]（Explain Like I'm 5）

很多人喜欢跟 AI 说：​“请把我当成小学生解释“，确实容易听懂，但也很容易停留在“好像懂了”的阶段。

这个 Prompt 让 AI 分别从小白和专家的角度分别解释一遍，这样可以帮助使用者更好的学习。

```
我想学习的是：​【填写概念或问题】​。
请分两层解释：
第一层，小白版。用生活化的语言和一个具体例子，让完全没有基础的人也能听懂。
第二层，专业版。使用准确术语，讲清核心机制、适用边界和常见误解。
最后请整理出：
1.列出小白说法与专业术语的对应关系；
2.我最容易理解错的地方；
3.3个用于检查我是否真正理解的问题。
```
