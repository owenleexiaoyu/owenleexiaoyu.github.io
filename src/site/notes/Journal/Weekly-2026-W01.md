# 周五 2026-01-02

《鬼灭之刃无限城篇一：猗窝座再袭》（名字好长）终于出了高清资源，今天看完了。故事紧接着柱训练篇，无惨杀了首领，但也中了首领的圈套。但他也有自己的打算，把所有的鬼杀队成员都拉到了无限城中，这里聚集了无数鬼，还有好几位上弦鬼。这部电影主要讲述两个主线：蝴蝶忍对战童磨，但不敌对方，被童磨吃掉，包含了蝴蝶忍的过往回忆；炭治郎和义勇对战猗窝座，也讲述了猗窝座变成鬼之前的故事。最终，炭治郎和义勇合力战胜了猗窝座。我感觉非常好看，特别燃。

和小萌下午玩了一会《双影奇境》。

晚上和小萌去松江看主题为「卡拉永远 OK」的金曲演唱会，巧合的是同事傅斌竟然和我们买到同一场的票，但我们最终也没见上面。演唱者是一个乐队，叫做像素谜题，主唱是一男一女。他们演唱了很多港台那边非常知名的金曲，比如《红日》《十年》《失恋阵线联盟》等。氛围很好，特别嗨，有些熟悉的歌可以跟着唱，小萌挥舞着灯条，特别开心。
