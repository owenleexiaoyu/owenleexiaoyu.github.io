# 周五 2026-06-19

今天是端午佳节，我们在老家过端午节。早上醒来后发现姑姑、姑丈、雪琪也过来给奶奶送节。中午做了很多菜，有猪蹄、鸡等硬菜。和雪琪、慧淇聊了会天，讨论雪琪的创业计划。雪琪目前在老家做钩织的活，之前是兼职，现在算是全职了。听她讲，之前她是接单，做一些钩织的花卖给主播。现在在逐渐脱离自己做，往中间商发展，从别的兼职的人手里收半成品，然后自己加工成更发卡等成品，再卖出，能比之前获得更高的收益，并且更轻松，她还在考虑自己做直播，自己卖成品。我们在讨论如何进一步发展，我的思路就是
- 要发展线下帮她做钩织的人（不过据说上手不太容易，需要时间学习）；
- 做一些高复购率的产品，她提到之前做的花，复购率就很低，买一两朵就不会再买了，但是类似泡泡玛特的一些 IP 形象，肯定会有很高的复购率（有侵权风险，不能在正规渠道卖）；
- 尽可能形成规模，往更上一层做，不是以劳动获取收益，而是以产品、资本获取收益
- 先确定收入目标，比如当前是每个月 3000，怎样能在 1 年内达成每个月 6000？从这个目标去想方法。
慧淇也给了一些很有用的思路，就是用钩织做一些造景，可以把泡泡玛特的玩偶、某个 IP 的角色立牌等等放到这个造景中。感觉是个很好的想法。
