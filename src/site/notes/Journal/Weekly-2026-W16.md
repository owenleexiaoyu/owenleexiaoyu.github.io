# 周五 2026-04-17

早上想洗个澡，结果热水器出不了热水了，在浴室里开热水，听见外面热水器响了一小会，就停止了，试了几次都是这样，一直没有热水。出来检查，发现开热水时，热水器的响声明显和正常工作时不一样，好像一直在尝试点火但点不着的感觉，一会就停止了。打电话找物业，物业处理不了这个。我看到热水器的牌子是林内，想着找这个牌子的官方维修应该会比在外面随机找个维修师傅靠谱。（之前我们在上个租房，找人修过热水器，收我们大几百，但感觉他是在乱修，上来给我们换个热水器主板，结果换了也不好使，后面还是换了卫生间的花洒才好，就是卫生间水压太低了）

晚上回来继续指挥 AI 写代码，昨天我是双开 Android Studio 和 Cursor，Cursor 中没有 Sync，代码高亮、跳转这些做不到，也没法编译，所以我是在 Cursor 中让 AI 生成代码，然后回到 Android Studio 编译。今天我想起 IDEA 通过 ACP 可以接 Cursor，所以我下载了最新的 IDEA，装了 Android 插件、KMP 插件，一样可以开发 Android 项目，然后下载一个 Jetbrains AI Assistant 插件，通过 ACP 关联到我的 Cursor，就可以把工作流收到一个 IDE 里了。目前相比在 Cursor 中，圈选代码，无法添加到 Prompt 里（这是 Jetbrains AI Assistant 的付费功能）。今天我又让 Cursor 帮我写了 WanAndroid 的个人页，这次提示更少，只有一张图片，但它也是很快就写出来了，并且效果还原度达到 95%。
