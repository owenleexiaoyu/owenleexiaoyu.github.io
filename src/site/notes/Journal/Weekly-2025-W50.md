# 周一 2025-12-08

感冒还很严重，今天请了一天病假在家休息。在日本玩时，曾听小萌的同事在聊《鬼灭之刃》这部动漫，正好最近也没啥剧看（唐诡 3 看完了），心血来潮便找来资源看。它主要讲述一个人与鬼之间的战斗，鬼以人为食，且有再生能力，很难被杀死，但他们无法接触阳光，否则会灰飞烟灭。为了对抗鬼，人类中诞生了一个以杀鬼为目标的鬼杀队组织，他们都是强大的剑士，用特制的日轮剑砍掉鬼的脑袋，就能杀死鬼。主角名为灶门炭治郎，他的母亲和弟弟妹妹一夜之间都被鬼所杀，唯一存活的妹妹祢豆子却成了鬼，但她似乎有些不一样，能够忍受吃人的欲望，同时有自己的意识，会保护炭治郎。为了找到将祢豆子恢复成人的方法，炭治郎就拜入剑士训练师门下，学习剑术，成为一名鬼杀队队员。讲述了他和他的小伙伴伊之助、善逸一起杀鬼、成长的故事。故事主线很清晰，非常好看，我今天一天就把第一季《立志篇》看完了。

# 周五 2025-12-12

今天还是居家办公，晚上和小萌一起去五角场万达看了新上映的《疯狂动物城 2》，小兔子警官朱迪和狐狸尼克成了动物城的警官，这次他们又将经历怎样的冒险呢？故事很流畅，我觉得完成度很高，画面特别精美，音乐动听，这是我们喜欢它的重要原因。节奏确实挺快的，感觉一直在跑跑跑、追追追。故事以山猫家族窃取了蛇祖母气候墙的研究成果，并制造命案诬陷蛇，将爬行动物都赶出动物城，并借机扩张冰川镇。此后山猫家族就成了动物城里最有势力的家族，甚至能够操纵市长。尼克、朱迪和小蛇盖瑞一起揭穿了山猫家族的阴谋。反正就是好看，哈哈哈。

# 周六 2025-12-13

今天我们又去徐泾看房啦，小萌约了个链家的中介，带我们看了万科天空之城二期云之谷的三套房子，有两套是双南户型，一套是南北通户型，我们比较相中双南户型，90 平左右，每个空间都相对均匀，有专门的餐厅区域，厨房挺大，还有岛台，卫生间是淋浴、洗手盆、马桶三分离，可供多人同时使用。后面又去看了高架对面招商虹桥公馆二期南、北小区里的两套房子，其中一套是两房、一套是小三房，招商的小区看着也挺不错的，而且楼层不高，很多是 11 层、14 层的小高层，没有连廊、公摊要小一些，但距离地铁站还是有点距离，实测从小区门口走到地铁检票处要十分钟。我们看了一圈下来，觉得万科二期确实不错，就在商场旁边，到商场、地铁都很方便。不过目前价格还有点高于我们的预期，90 平要 530，虽然说是包含了车位的价格，但我们觉得还是有点贵，我们希望能降到 450 左右，我们就能出手了，希望明年再给力一点，降降降。

给一些同学发了婚礼的邀请，大学里玩的好的五个同学：屹东、勇昊、浩然、建贞、远哥都说了要来，非常开心。
